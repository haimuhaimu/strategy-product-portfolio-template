# v0.3.0｜证据驱动作品集高星冲刺版

v0.3.0 暂停扩展功能，集中改善首次理解、真实证据、Showcase 贡献路径与发布完整性。

## 本版交付

- README 首屏统一定位为“面向产品经理与运营的证据驱动作品集系统”，明确 Agent Skill 是访谈与证据审计引擎，网站是输出。
- 首屏展示适用人群、三项交付、真实作品截图，以及在线作品集、在线配置器与 Agent Skill 三个入口。
- 新增维护者真实 Before / After 自测案例，完整展示原始材料、唯一追问、补充证据、最终叙事与 strict audit 实际五维评分。
- 新增低冲突 Showcase：一位贡献者一个 JSON，包含 schema、首个维护者自测条目、自动校验和公开披露流程。
- package 与 lockfile 版本更新到 `0.3.0`，同步变更记录与发布说明。

## 隐私与证据边界

Showcase 只接收公开 HTTPS URL、角色标签、公开亮点、审计摘要和明确披露确认；不接收邮箱、内部链接或原始敏感材料。首个案例明确标记为 `maintainer/self-test`，不是第三方客户案例。

案例只使用维护者已确认事实：过去通常需要 1 名 DA 或 1 名算法同学写 SQL、制定策略；现在产品和运营可借助 AI 内容理解与自动化策略自行完成；覆盖全量业务作者、几十万量级；相关策略已经实际应用。未披露收入、提升比例、具体组织或时间。

## 校验

发布前执行完整 Node tests、Skill 审计、Python audit tests、`data/projects.json` strict audit、lint、build、SEO、GitHub Pages 模拟构建和 `git diff --check`。具体结果以本版本提交及 CI 为准。

## 升级

本版没有修改 Skill 逻辑或作品集数据 schema。已有 `data/projects.json` 可继续使用；拉取代码后运行 `npm ci && npm run build` 即可。
