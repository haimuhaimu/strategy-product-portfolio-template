# Portfolio Story Builder Skill

`portfolio-story-builder` 把简历、项目经历和零散材料转成可投递的产品经理或运营作品集。它不会只做文案润色，而是先补齐事实，再选择最能证明岗位能力的 3 个案例，最后输出可审计、可进入网页模板的 v2 `projects.json`。

## 用户价值

- 从全部经历中选择 3 个互补案例，而不是默认采用最先提到的项目。
- 一次只追问一个高价值问题，降低整理材料的负担。
- 用 0–5 分证据评分检查结果、口径、方法、交付物和个人贡献边界。
- 用“招聘官 30 秒测试”和挑战模式重排信息、去掉空话与越界归功。
- 在生成和发布前执行结构、内容质量与常见隐私模式审计。

## 触发示例

可以对支持 Agent Skills 的 Agent 说：

- “把我的简历做成产品经理作品集。”
- “帮我从这些经历里选 3 个最适合投增长运营的案例。”
- “运营项目怎么写得有证据，不像活动流水账？”
- “把项目材料生成可投递作品集，并做隐私检查。”

## 工作流

1. 盘点简历、项目经历与证据材料。
2. 判断 `product`、`operations` 或 hybrid 主叙事。
3. 每轮只追问一个最关键的证据缺口。
4. 从全部经历中精选 3 个互补案例。
5. 执行证据评分、去水分、挑战模式与招聘官 30 秒测试。
6. 执行隐私红线检查。
7. 生成并审计 v2 `projects.json`。
8. 将数据接入网页模板并完成测试、构建与预览。

## 如何使用

将 [`skills/portfolio-story-builder`](portfolio-story-builder/) 目录安装到支持 Agent Skills 的客户端，或直接让 Agent 读取 [`SKILL.md`](portfolio-story-builder/SKILL.md) 并按其中流程执行。不同客户端的安装方式可能不同，本仓库不提供未经验证的第三方安装命令。

## 与网页模板的关系

Skill 是内容生产与质量控制主线；本仓库的 Next.js 网站是它的一个输出载体。Skill 生成的 v2 `projects.json` 可接入仓库中的 `data/projects.json`，然后通过静态构建得到可投递网站。`/config/` 可视化编辑器继续作为不使用 Agent 时的 fallback，而不是核心工作流。

## 隐私承诺

Skill 和网页模板均可在本地运行，不要求账号、后端数据库或上传原始简历。审计器只读取调用时指定的本地 JSON，使用 Python 标准库，不发送网络请求。自动扫描只能发现常见风险；发布前仍需本人确认组织保密要求、指标披露范围、截图授权和联系方式。
